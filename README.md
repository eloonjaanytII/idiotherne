# О проекте
##
Idiotherne  - проект, истоком которого служит моё недовольство к устаревшему интерфейсу личного профиля Кинопоиска, и чьё концептуальное наполнение было вдохновлено фильмами Ларса фон Триера.
## Что предлагает на данный момент
На данный момент реализованы 10 основных вкладок:<br/>
### 1. Регистрация/Авторизация
Регистрация происходит в два этапа. На первом этапе пользователю необходимо ввести валидную почту, никнейм и пароль. На втором этапе выбрать пол, а также своё тотемное животное из предложенного списка, которое и будет являться его аватаром.<br/>
Для зарегистрированных пользователей вход осуществляется с помощью никнейма и пароля.
### 2. Страница пользователя
Пользователю доступны 4 вкладки:<br/>
1. Рецензии. Здесь пользователь может написать рецензию фильму на основе всплывающего поиска. Снизу отображается список. </br>
2. Оценки. Здесь виден список фильмов с оценками пользователя. </br>
3. Просмотренное. Просмотренные пользователем фильмы </br>
4. Избранное. Избранные пользователям фильмы </br>
Также доступен график с распределением фильмов по жанрам.
### 3. Различные топы фильмов и сериалов с постраничнм выводом
### 4. Фильмы, сериалы и мультфильмы с возможностью фильтрации по годам/жанрам/странам
Клик на карточку с фильмом пересылает на страницу с общей информацией о фильме, главных актёрах, режиссёре и операторе. Снизу доступны все написанные рецензии к фильму.</br>
При клике на актёра - соответсвенно страница с актёром.
### 5. Список присоединённых пользователей
В верхней панели доступна смена темы с тёмной на светлую, поисковая строка.

## Техническая составляющая
### Frontend:
1. Вёрстка, стилизация и адаптивность реализованы с помощью HTML/Tailwind/DaisyUI/TS. </br>
2. Маршрутизация выполнена с использованием react-router-dom
3. Выбор сборщика пал на Vite.
4. В качестве фреймоворка применялся React.
5. Для state-менеджмента использовался Redux Toolkit.
6. Для запросов с серверов использовалась библиотека RTK-query.
7. Валидация и создание форм проводилось с помощью библиотеки react-hook-form
8. Карусель фильмов была написана с помощью библиотеки bear-react-carousel
### Backend:
Проект построен по слоистой архитектуре, условно разделённой на:
- routes
- controllers
- services
- models
- middlewares
- utils

1. Node.js — среда выполнения JavaScript на сервере.
2. Express — для построения REST API, реализует маршрутизацию, middleware и структуру проекта.
3. В качестве базы данных используется СУБД PostgreSQL. 
4. ORM - Sequelize, через который описываются модели (пользователи, фильмы, отзывы и т.д.).
5. Авторизация сделана через JWT access токен. Для хеширования использовалась библиотека bcrypt.
6. Для валидации ответов и запросов использовалась библиотека zod.
7. В качестве источников фильмов использовалась неофициальная база данных кинопоиска https://kinopoiskapiunofficial.tech/

### API
REST API организовано по принципам RESTful. Доступны маршруты для:
- Регистрации и логина пользователя (`/auth`)
- Получения и добавления рецензий (`/reviews`)
- Работы с флагами просмотра/оценки (`/films/flag`)
- Получения информации о фильмах, актёрах и пользователях.

### Развёртывание:
- Сервер развёрнут на VPS.
- Запуск производится через PM2.
- Настроен reverse proxy через Nginx для перенаправления запросов на порт фронтенда и API.
- Используется .env для хранения ключей (включая API-ключ Кинопоиска).
